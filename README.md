Classificador de Perfis com Algoritmo 1-NN

Projeto desenvolvido em Python para classificação de usuários utilizando o algoritmo 1-Nearest Neighbor (1-NN) e a distância euclidiana.

Objetivo

Classificar um novo usuário em um dos perfis (P1, P2 ou P3) com base na similaridade dos seus atributos em relação a uma base de dados previamente classificada.

Atributos Utilizados
Download médio diário (MB)
Upload médio diário (MB)
Número médio de acessos simultâneos
Tempo médio de conexão por dia (minutos)
Conceitos Aplicados
Python
Funções
Listas e Matrizes
Estruturas de Repetição
Estruturas Condicionais
Distância Euclidiana
Algoritmo 1-NN
Como Executar
python main.py

Informe os dados solicitados e o sistema retornará o perfil mais semelhante encontrado na base de dados.
